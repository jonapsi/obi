# Registro de decisiones de arquitectura (ADR)

Cada ADR registra una decisión, su contexto y sus consecuencias. Las decisiones de noviembre de 2026 vienen de los documentos del proyecto Obi (decisiones de arquitectura y modelo de datos para DRF).

Para cambiar una decisión, se escribe un ADR nuevo que la reemplace y se marca el anterior como `Reemplazada por ADR-XXXX`.
